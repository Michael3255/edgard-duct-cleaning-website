# Edgard Duct Cleaning LLC — Website

Rough-draft brochure site, built with [Astro](https://astro.build) + Tailwind.

## Local development

```bash
npm install
npm run dev
```

Then open http://localhost:4321.

## Build

```bash
npm run build
```

Output goes to `dist/`.

## Documentation

See the [docs](docs/README.md) for architecture, the development guide, content editing and git workflow.
